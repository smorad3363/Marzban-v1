# Marzban V1.0.0

Marzban V1 establishes the new canonical `1.0.0` product baseline from the reviewed mature source.

- Plans are commercial entitlements for traffic, duration, price, reset policy, and device limits.
- Access Groups exclusively own user network access through Nodes, Inbounds, and Hosts.
- Existing mature hierarchy, billing, backup, MySQL migration, security, and release-integrity behavior remains preserved.
